# vrs-cli

A command line tool for Verisense blockchain & AVS.

```
Command line tool for interacting with Verisense network

Usage: vrx [OPTIONS] <COMMAND>

Commands:
  account  Account management subcommand
  nucleus  Nucleus management subcommand
  balance  Balance subcommand
  help     Print this message or the help of the given subcommand(s)

Options:
  -v, --verbose            Display verbose output
      --devnet             Connect the devnet
      --rpc <RPC>          The custom RPC endpoint to connect to. E.g. "ws://localhost:9944"
      --vrx-dir <VRX_DIR>  The vrx home path, default to "~/.vrx"
  -k, --key <KEY>          The private key file to use, default "~/.vrx/default_key"
  -h, --help               Print help
  -V, --version            Print version
```
